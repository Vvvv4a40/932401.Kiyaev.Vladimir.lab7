# Лабораторная работа №7

REST API на ASP.NET Core (.NET 10) для билетов на мероприятия, вариант 12. Данные хранятся в SQLite через Microsoft.Data.Sqlite. Фронтенд в `public` обслуживается тем же сервером.

## Запуск

```bash
dotnet run --project Lab7.csproj
```

После запуска страница доступна по адресу `http://localhost:3000`.

Требуется .NET SDK 10. При первом запуске NuGet восстановит зависимости. Порт можно изменить переменной `PORT`, переменной `ASPNETCORE_URLS` или аргументом `--urls`:

```bash
dotnet run --project Lab7.csproj -- --urls http://localhost:3007
```

База по умолчанию — `data/tickets.db` в каталоге лабораторной при `dotnet run`, либо рядом с DLL в опубликованном приложении. Существующие SQLite-файлы и схема совместимы. Переменная `DATABASE_PATH` задаёт другой путь, в том числе путь к существующей базе при публикации. При пустой таблице сервер добавляет четыре демонстрационных тарифа.

## API

- `GET /api/tickets` — все тарифы;
- `GET /api/tickets?event_id=7` — фильтр по событию;
- `GET /api/tickets/:id` — один тариф;
- `POST /api/tickets` — создание;
- `PATCH /api/tickets/:id` — изменение;
- `POST /api/tickets/:id/purchase` — покупка и уменьшение остатка;
- `DELETE /api/tickets/:id` — удаление.

Таблица `tickets`: `id`, `event_id`, `type`, `price`, `remaining`. Тип — `general` или `vip`, цена и остаток неотрицательны, идентификатор события — положительное целое. Числовые поля также принимают строки из HTML-формы. `PATCH` частично изменяет тариф. Покупка принимает `quantity` (по умолчанию 1) и выполняется в транзакции, поэтому при недостаточном остатке изменение откатывается. Параллельные покупки не могут продать больше билетов, чем осталось.

## Проверка

```bash
dotnet run --project tests/Lab7.Tests.csproj
```

Интеграционные проверки поднимают сервер на свободном порту с временной SQLite-базой и проверяют CRUD, валидацию, откат покупки, параллельные покупки, статические файлы и сохранение данных после перезапуска. Рабочая база не затрагивается.

Для публикации:

```bash
dotnet publish Lab7.csproj -c Release -o publish
```
